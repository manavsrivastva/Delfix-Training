==================================================
MODULE 2 - TOPIC 2: ROLES AND PRIVILEGES
==================================================

--------------------------------------------------
1. SYSTEM ADMINISTRATOR
--------------------------------------------------
* Responsible for managing the Delphix Engine ITSELF, but NOT the objects
  (Environments, dSources, VDBs) within the server.
* Default system administrator user: "sysadmin".
* This user can be suspended, but it may NOT be deleted.

--------------------------------------------------
2. THE DELPHIX ADMINISTRATOR (ADMIN)
--------------------------------------------------
The Delphix Administrator can assign privileges to different users.

Special privileges:
  1) A Delphix user can be marked as a Delphix Administrator.
  2) They implicitly have Owner privileges for all Delphix objects.
  3) They can create new groups and new environments.

Delphix Admin users can further create users and assign one of the four
predefined user roles, then assign privileges to them.

--------------------------------------------------
3. THE FOUR USER ROLES
--------------------------------------------------
* Owner         - Full access; can perform actions like refresh,
                  rollback, snapshot, and start / stop / restart.
* Provisioner   - Can access data and provision VDBs.
* Data Operator - Can access data operations only.
* Reader        - Read-only access to data.

--------------------------------------------------
4. LDAP (LIGHTWEIGHT DIRECTORY ACCESS PROTOCOL)
--------------------------------------------------
LDAP is used if you intend to validate user logins against an external
directory service instead of only local Delphix accounts.
